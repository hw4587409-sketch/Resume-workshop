# 简历工坊｜AI 简历制作工具

一个可在电脑浏览器中本地运行的 HTML 简历制作工具。

## 快速开始
1. 下载并解压压缩包。
2. 使用 Chrome 或 Edge 打开 `Resume_Workshop.html`。
3. 按页面提示填写简历，完成后导出 PDF。

## v1.0 说明
本发布包基于用户提供的原始压缩包整理。为尽量保持原有功能，`Resume_Workshop.html` 程序代码未作修改。

原始使用说明列出的功能包括：
- 三种模板：原有简约版、黑色经典版、深蓝商务版
- 照片上传、经历板块增删
- 富文本加粗、编号/圆点分点
- 实时预览、智能排列为一页、PDF 导出

## 数据与隐私
简历内容保存在当前浏览器的本地存储中，不会自动同步到其他浏览器或设备。清除浏览器数据可能导致本地保存内容丢失。请勿在公共电脑上填写敏感个人信息。

## 使用环境
建议在 Windows 或 macOS 电脑上使用最新版 Chrome 或 Edge。手机浏览器对本地 HTML 文件、文件选择和 PDF 打印的支持可能存在差异，暂不保证完整体验。
