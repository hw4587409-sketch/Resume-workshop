简历工坊｜AI 简历制作工具 v1.0

【使用方法】
1. 下载并解压本压缩包。
2. 在电脑上使用 Chrome 或 Edge 浏览器打开 Resume_Workshop.html。
3. 填写个人信息、教育经历、工作经历及其他简历内容。
4. 可按需上传个人照片、切换模板和调整排版。
5. 完成后使用页面中的 PDF 导出功能保存简历。

【当前版本功能】
根据原始压缩包中的使用说明，本版本包含：
- 模板一（原有简约版）、模板二（黑色经典版）、模板三（深蓝商务版）
- 照片上传、经历板块增删
- 富文本加粗、编号/圆点分点
- 实时预览、智能排列为一页、PDF 导出

【数据与隐私】
简历内容保存在当前浏览器的本地存储中。更换浏览器或清除浏览器数据后，内容不会自动同步。请勿在公共或他人电脑上输入不希望他人看到的个人信息。

【使用建议】
建议优先在 Windows 或 macOS 电脑上使用最新版 Chrome 或 Edge。手机浏览器对本地 HTML 文件打开、文件保存及 PDF 打印的支持可能不同，暂不保证手机端完整体验。导出 PDF 前请检查个人信息、照片、经历内容及分页效果。
